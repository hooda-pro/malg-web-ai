# لفطومتي ❤️ — موقع هدية عيد ميلاد

موقع صغير اتعمل بحب، تجربة قصة تفاعلية كاملة (مش مجرد صفحة):
شاشة ترحيب سينمائية (بتظهر في كل مرة يفتح فيها الموقع) ← فصول الحكاية ← خط الزمن (بيتملّي مع السكرول) ← ذكريات الكلام (مقفولة بقفل بيفتح بوب أب سؤال تاريخ الميلاد، وبعد الإجابة بتفتح بحركة) ← الرسالة ← رسالة مخفية ← عيد الميلاد والعداد ← زر "افتحي الألبوم" (بيفتح بوب أب يسأل: اي اكتر كلمتين بحب اسمعها منك؟ — ولازم الإجابة فيها قلبها و قلب مزتك — وبعدها الصور تظهر جوه البوب أب وبعدين الألبوم بيتفتح بأنيميشن وصور قابلة للتنزيل).

يعمل على أي موبايل أو كمبيوتر — مفيش أي برامج مطلوبة، ملفات HTML/CSS/JS عادية.

---

## طريقة التشغيل

### الطريقة الأسهل
افتح ملف `index.html` بأي متصفح (كليك مزدوج) — هيشتغل على طول.

### الأفضل (اختياري)
لو هتشارك الموقع عبر لينك، ارفعه على استضافة ثابتة زي:
- **GitHub Pages** (مجاني): اعمل Repo وارفع الملفات، وفعّل Pages.
- **Netlify / Vercel**: اسحب المجلد وحطه — يديك لينك على طول.

> بعد ما يبقى عندك لينك، حطه في `js/content.js` داخل `meta.url`
> عشان المشاركة والمعاينة يبقوا مظبوطين.

## تعديل المحتوى (أهم جزء)

**كل حاجة بتتعديل من ملف واحد: `js/content.js`**

| عايز تغير | فين في content.js |
|---|---|
| أسمها وألقابها | `her` |
| تاريخ عيد الميلاد والعمر | `birthday` (dateISO, ageOnBirthday, bigLine...) |
| نص شاشة البداية | `hero` |
| فصول الحكاية (البطاقات) | `chapters` |
| مراحل خط الزمن | `timeline` |
| جمل "كلام لسه فاكره" | `chat.bubbles` |
| بوب أب تاريخ الميلاد قبل الرسايل | `gate.memories` (التاريخ في `gate.memories.myBirthday`) |
| بوب أب سؤال الكلمتين قبل الألبوم | `gate.album` (الكلمتين في `gate.album.ask.answers`) |
| الصور ووصفها وتواريخها | `gallery.images` |
| الرسالة | `letter` |
| الرسالة المخفية | `secret` |
| نص المشاركة | `share` |
| الفوتر | `footer` |

## الصور

- الصور موجودة في `assets/images/` باسم `photo-01.jpg` لحد `photo-19.jpg` مرتبة بالتاريخ.
- عايز تستبدل صورة؟ حط الصورة الجديدة **بنفس الاسم** مكان القديمة وخلاص.
- عايز تضيف صورة جديدة؟ حطها في المجلد (`photo-20.jpg`) وزود سطر في `gallery.images`.
- الوصف والتاريخ لكل صورة في `js/content.js`.
- لو صورة ناقصة، الموقع بيعرض مكان واضح مكتوب فيه اسم الملف — مش هيبوظ الشكل.

## المعاينة عند المشاركة

لما اللينك يتشارك على واتساب/فيسبوك بيظهر معاينة جميلة:
- الصورة: `assets/social/og-cover.png` (تقدر تغيرها بأي صورة 1200×630 بنفس الاسم)
- العنوان والوصف: في `<head>` داخل `index.html` (OG + Twitter) وفي `js/content.js`
- لو غيرت العنوان أو الوصف، غيّرهم في المكانين عشان يفضلوا متطابقين.

## الملفات

```
index.html            الصفحة الرئيسية
css/                  base.css (الأساسيات) / components.css (المكونات) / sections.css (الأقسام)
js/
  content.js          ← كل المحتوى القابل للتعديل
  effects.js          الخلفية المتحركة + أنيميشن الظهور + الكونفيتي
  story.js            فصول الحكاية + خط الزمن + الشات
  gallery.js          الصور + الألبوم + التنزيل
  gate.js             بوب أب: بوابة تاريخ الميلاد (الرسايل) + بوابة الكلمتين (الألبوم)
  countdown.js        العد التنازلي (بيتحول لرسالة يوم العيد)
  share.js            المشاركة + التوست
  settings.js         الإعدادات: وضع داكن / الخط (رقعة أو عادي) / إخفاء الشريط السفلي
  main.js             التشغيل
assets/images/        صور الذكريات
assets/icons/         الأيقونات
assets/social/        صورة المعاينة عند المشاركة
tools/                سكريبت توليد صور المعاينة والأيقونة (مش محتاجه عادة)
```

## ملاحظات تقنية سريعة

- الموقع Mobile-First وسريع: صور Lazy، أنيميشن CSS خفيف، وIntersectionObserver.
- شاشة الترحيب بتشتغل في كل مرة يفتح فيها الموقع — في كل الأحوال (ومعاه زر تخطي).
- تخفيف خاص للموبايل: من غير backdrop-filter تحت 900px، خلفية أهدأ، صور الألبوم بتحمّل أول ما يتفتح.
- الأنيميشن اجباري: الحركات شغالة في كل الأحوال حتى لو "تقليل الحركة" مفعّل من الموبايل.
- كل الأزرار شغالة: الفصول، الصور، الرسالة المخفية، المشاركة، الاحتفال.
- إعدادات المستخدم (وضع داكن، الخط رقعة/عادي، إخفاء الشريط السفلي) من أيقونة الإعدادات اللي تحت زر المشاركة — وبتتحفظ على الجهاز وتتطبق فورًا في كل زيارة.
