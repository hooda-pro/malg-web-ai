# mlag AI — النسخة الويب

نسخة موقع كاملة (Next.js) من تطبيق mlag AI الأصلي، بنفس الشخصية والمميزات:
شات فوري مع بث الرد لحظة بلحظة، بحث على الإنترنت، كروت ملفات/مشاريع قابلة للتحميل،
بيئة تشغيل كود (HTML/CSS/JS)، نظام حسابات وتوكنز، وتخزين حقيقي لكل حاجة على قاعدة بيانات Neon.

الشكل اتغيّر بالكامل لتصميم "تيرمنال/برمجة" أسود بخط مونو — لكن كل الميزات والمنطق
(نظام الكوتة، fallback الموديلات، صيغة ملفات المشروع، المتابعة عند القطع...) اتنقلت زي ما هي.

## المتغيرات المطلوبة (Environment Variables)

انسخ `.env.example` باسم `.env.local` (محليًا) أو ضيفهم في Vercel Project Settings:

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط الاتصال بقاعدة بيانات Neon (Postgres) |
| `JWT_SECRET` | نص عشوائي طويل وسري لتوقيع جلسات الدخول |
| `MLAG_API_KEY` | مفتاح API بتاع GLM (من bigmodel.cn) |
| `MLAG_MODEL` | (اختياري) اسم الموديل، افتراضيًا `glm-4.7-flash` |
| `ADMIN_EMAIL` | (اختياري) بريد حساب الأدمن، افتراضيًا `admin@mlag.ai` |
| `ADMIN_PASSWORD` | (اختياري) كلمة مرور الأدمن، افتراضيًا `Mlag@Admin2026` |
| `NEXT_PUBLIC_WHATSAPP_USERNAME` | (اختياري) يوزر واتساب الدعم لزر الشحن، افتراضيًا `GM-Y16` |

الجداول بتتنشئ تلقائيًا في أول طلب يوصل للسيرفر (مفيش سكريبت لازم تشغّله يدويًا)،
وحساب الأدمن بيتعمل تلقائيًا لو مفيش أي أدمن في القاعدة.

## لوحة الأدمن (`/#/admin`)

لوحة تحكم كاملة بتفتح من الرابط: **`https://malg-ai.vercel.app/#/admin`**

- **الدخول:** بحساب الأدمن (`admin@mlag.ai` / `Mlag@Admin2026` افتراضيًا —
  غيّرهم من متغيرات البيئة `ADMIN_EMAIL` و `ADMIN_PASSWORD` أو من قسم «الأمان» جوه اللوحة).
- **نظرة عامة:** إحصائيات كاملة (مستخدمين، محظورين، محادثات، رسائل، استهلاك التوكنز الكلي)،
  أكبر 5 مستهلكين، وأحدث المسجلين.
- **المستخدمين:** قايمة بكل الحسابات مع بحث بالاسم/الإيميل وشريط استهلاك التوكنز لكل واحد،
  وضغط على أي مستخدم يفتح صفحة تفاصيله الكاملة (الرصيد، المحادثات، آخر الرسايل، تواريخ النشاط)
  مع أزرار: **شحن توكنز** (إضافة/تعيين/تصفير)، **حظر/فك حظر**، و**حذف الحساب** نهائيًا
  (بتأكيد بكتابة الإيميل). حسابات الأدمن محمية من الحظر والحذف.
- **سجل الإجراءات:** كل حاجة بيعملها الأدمن بتتسجل تلقائيًا (حظر، شحن، حذف...).
- **الأمان:** تغيير كلمة مرور الأدمن.
- الحسابات المحظورة بتترفض في تسجيل الدخول وفي إرسال الرسايل حتى لو عندها جلسة قديمة.

مسارات الـ API الخاصة بالأدمن كلها محمية بفحص `is_admin` من الجلسة: `api/admin/*`.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`.

## النشر: GitHub + Vercel + Neon

### 1) إنشاء قاعدة بيانات Neon
1. روح على [neon.tech](https://neon.tech) واعمل مشروع جديد.
2. من الـ Dashboard انسخ الـ **Connection String** (بيبدأ بـ `postgres://...`).
3. حطه في متغير `DATABASE_URL`.

### 2) رفع الكود على GitHub
```bash
git init
git add .
git commit -m "mlag AI web"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

### 3) الربط مع Vercel
1. روح [vercel.com](https://vercel.com) → New Project → اختار الـ repo.
2. Vercel هيكتشف إنه مشروع Next.js تلقائيًا (مفيش إعدادات إضافية مطلوبة).
3. في خطوة الإعداد، ضيف الـ Environment Variables الأربعة اللي فوق.
4. دوس Deploy.

بعد أول Deploy، أول حد يسجّل حساب أو يبعت رسالة، الجداول هتتنشئ تلقائيًا في Neon.

## ملاحظة أمان

مفتاح `MLAG_API_KEY` في `.env.example` هو نفسه اللي كان موجود في مشروع الأندرويد الأصلي.
لو المشروع القديم اترفع على مكان عام (زي GitHub عام) قبل كده والمفتاح ظهر فيه،
يفضل تعمل له **Rotate** من لوحة تحكم bigmodel.cn قبل ما تستخدمه هنا، وميتحطش أبدًا
كمتغير `NEXT_PUBLIC_*` (المتغيرات العادية هنا سيرفر-فقط، آمنة).

## بنية المشروع

```
app/
  layout.tsx, page.tsx, globals.css       ← الصفحة الرئيسية (+ راوتر #/admin)
  api/
    auth/{register,login,logout,me}       ← تسجيل الدخول
    sessions/                             ← إدارة المحادثات
    messages/[sessionId]                  ← جلب رسائل محادثة
    chat/route.ts                         ← إرسال رسالة (streaming)
    chat/continue/route.ts                ← متابعة رد مقطوع
    quota/route.ts                        ← رصيد التوكنز
    admin/                                ← لوحة الأدمن (stats, users, logs, password...)
lib/
  db.ts            ← الاتصال بـ Neon + إنشاء الجداول + حساب الأدمن التلقائي
  auth.ts           ← جلسات JWT + فحص الأدمن والحظر
  adminGuard.ts     ← حماية مسارات الأدمن + تسجيل الإجراءات
  systemPrompt.ts   ← شخصية mlag وتعليماته (نفس التطبيق الأصلي)
  ai.ts             ← الاتصال بموديل GLM + fallback + رسائل الأخطاء
  quota.ts          ← منطق رصيد التوكنز والتجديد كل أسبوع
  recharge.ts       ← باقات الشحن + رابط واتساب الدعم (wa.me/username)
  parseContent.ts   ← استخراج ملفات المشروع من رد الموديل
components/         ← واجهة المستخدم (React)
components/admin/   ← واجهة لوحة الأدمن
```

## المميزات المنقولة من التطبيق الأصلي

- شخصية mlag والتعليمات الكاملة (اللهجة المصرية، متى يذكر المطوّر، صيغة الملفات...)
- بحث حي على الإنترنت (web_search tool)
- نظام رصيد توكنز: 500,000 توكن للمسجلين، تجديد تلقائي بعد أسبوع من النفاد
- شحن الرصيد: باقات توكنز (250K / 500K / مليون / 2.5 مليون — مليون = 100 جنيه) وزر تحويل
  على واتساب الدعم برسالة جاهزة فيها بيانات الحساب والباقة، والأدمن بيضيف الرصيد من لوحة الأدمن
- إعادة محاولة تلقائية عند ضغط السيرفر (429) وتبديل الموديل عند الفشل
- استخراج ملفات/مشاريع من الرد (```lang path="..."```) وعرضها كـ "كارت ملف" قابل للتحميل
  (ملف واحد أو zip للمشروع كامل)
- زرار "متابعة" لما الرد يتقطع بسبب طول الرد
- زرار إيقاف أثناء البث
- بيئة تشغيل كود حي (HTML/CSS/JS) داخل iframe معزول
- تخزين حقيقي لكل حاجة (المحادثات، الرسائل، الرصيد) على Neon بدل التخزين المحلي القديم
