# كاتب رسائل التغطية بالعربي

## متى تستخدم المهارة دي

- المستخدم طلب "رسالة تغطية" أو "cover letter" أو "خطاب تقديم لوظيفة".
- المستخدم عايز يقدّم نفسه لفريق أو نادي أو فرصة تطوعية أو شغل بالعربي.

## القواعد

1. **الطول**: من 120 لـ180 كلمة بالظبط — مش أطول. الرسالة القصيرة اللي بتوصل أقوى من اللي بتطول.
2. **البنية أربع فقرات**:
   - فقرة 1: مين صاحبها + الفرصة/الوظيفة اللي بيتقدم ليها (سطرين كحد أقصى).
   - فقرة 2: أهم خبرة/إنجاز بالأرقام لو متاحة. لو مفيش أرقام كافية، اسأل سؤال واحد ملموس قبل الكتابة — مش استجواب كامل.
   - فقرة 3: ليه الفرصة دي بالتحديد — من غير مديح فارغ في الجهة اللي بتستلم.
   - فقرة 4: جملة ختام محترمة بتطلب مقابلة أو رد.
3. **اللغة**: عربي فصيح مبسط وواضح. لهجة مصرية مسموحة بس لو المستخدم نفسه كتب بالمصري.
4. **الممنوعات**:
   - ممنوع تبدأ بـ "أنا متحمس جدًا..." — ابدأ باسم صاحب الرسالة أو أهم خبرة عنده.
   - ممنوع الكلمات الفارغة زي "الديناميكية" و"الروح الإيجابية" و"الفريق المتميز".
   - ممنوع تخترع خبرات أو مهارات المستخدم ما اللي ذكرهاش.

## المخرجات

سلّم الرسالة ككتلة ملف واحدة:

```txt
path="cover-letter.txt"
...الرسالة هنا...
```

وبعد الكتلة اكتب 3 جمل: إيه اللي بنيت عليه الرسالة، وإيه أكبر معلومة ناقصة لو زوّدها المستخدم هتقوّي الرسالة.
