# MALG — شكل الموبايل المخصوص ("MALG Pocket" mobile skin)

المطلوب: تليفون شكله مختلف تمامًا عن الديسكتوب والتابلت — مش تعديل على الشكل
الحالي، دي لغة تصميم جديدة للموبايل: عصرية، سريعة، ناعمة، بموشن جرافيك وأنيميشن.

## أهم نقطة: الكمبيوتر والتابلت مش متأثرين إطلاقًا

كل حاجة في `@media (max-width: 639.98px)` — يعني التليفون (حتى ٦٣٩px عرضًا)
هو الوحيد اللي بياخد الشكل الجديد. من ٦٤٠px لفوق (تابلت/كمبيوتر) الأصلي شغال
زي ما هو ١٠٠٪ حرف فحرف.

## الملفات اللي اتعملت / اتعَدلت

| ملف | الحالة | وظيفته |
| --- | --- | --- |
| `app/mobile.css` | **إعادة كتابة كاملة** | السكِن المخصوص للموبايل: مشهد حي، هيدر كبسولة، هيرو بطول الشاشة، كومبوزر بحيط نوري، شات بستايل جديد، حركات spring |
| `components/MobileAmbience.tsx` | **جديد** | ٣ كرات ضوء بتنسم + parallax مع السكرول + خط تقدم القراءة (بيتمالي من يمين). مش بيرسم حاجة على الديسكتوب ولا مع تفضيل "تقليل الحركة" |
| `app/layout.tsx` | تعديل | ترتيب استيراد الـCSS (الموبايل آخر واحد عشان يكسب الكاسكيد) + تركيب MobileAmbience |
| `next.config.mjs` | تعديل | `allowedDevOrigins` — للتطوير المحلي بس، مالوش تأثير على الإنتاج |
| `public/preview.html` | **جديد** | صفحة معاينة فيها إطار تليفون حقيقي (٣٦٠/٣٩٠/٤٣٠px) جواه الموقع نفسه — تشوف شكل الموبايل من غير ما تفتح تليفون فعلي |

## تفاصيل الشكل الجديد

### أول ما الصفحة تفتح
- إضاءة محيطية: wash ناعم بيتنفس ببطء خلف كل صفحة (transform/opacity فقط — ناعم على GPU).
- الهيدر بقى **كبسولة زجاج عايمة** بدل شريط ملاصق.
- الهيرو بياخد **طول الشاشة كامل** والعناصر بتظهر بـ spring pop متدرج.
- الجملة الملونة في العنوان عليها شراقة ضوء (sheen) تمشي عليها بشكل متكرر.

### الهيرو والكومبوزر
- الكومبوزر بقى كارت زجاجي بحيط نوري بيجري حوالين حوافه.
- شيبس المودات (ابنِ / اكتب / ابحث / تعلّم): تمرير أفقي بـ snap، والشيب النشيط بتدرج لون كامل.
- زر الإرسال: أكبر (46px) بضل نابض خفيف.
- الأمثلة السريعة بقت كاروسيل أفقي بـ snap — مش سطور ملفوفة.

### أثناء التصفح
- خط تقدم القراءة رفيع ملوّن أقصى الصفحة بيتعبّى مع أي سكرول (حتى داخل الشات).- كل كروت الأقسام بتترتد دخول، وأي زر ليه حالات ضغط spring.
- الماركي (قائمة القدرات) أسرع وشكله أنعم.

### المنيو والشات
- منيو الهيدر: شيت ينزل تحت الكبسولة مع تصفير خفيف للخلف — صفوف 52px على قد الصباع.
- الشات: توب بار كبسولة عايمة زي الهيدر، درَور التاريخ بيدخل بنزة من طرفه،
  رسايل المستخدم بقت فقاعات بتدرج اللون (terracotta) بزاوية ذيل، الكومبوزر دِك زجاج عايم.

### أمان اللمس والأداء (A11y)
- أهداف لمس 44px+ في كل مكان.
- مفيش زوم من iOS (الحقول 16px).
- ممنوع أي تمرير أفقي مفاجأ.
- `prefers-reduced-motion` → كل الأنيميشن/الترانزيشن بيقف بالكامل.
- الحركة كلها `transform`/`opacity` فقط — 60fps بدون reflow.

## تشغيل المعاينة

```bash
pnpm install      # أو npm install
pnpm dev          # أو npm run dev (المنفذ افتراضي 3000 — أو استخدم -p)
```

لو شغّلت بالمنفذ 4391 زي المعاينة الجاهزة: افتح <http://localhost:4391/preview.html>

هتلاقي صفحة "معاينة شكل الموبايل — MALG Pocket" فيها:
- إطار تليفون iPhone جواه الموقع الحقيقي (٣٩٠px).
- زراير لتغيير مقاس التليفون (iPhone SE / 14 / 16 Max).
- يمكن تصفح أي صفحة جوه الإطار — بما فيها `/#/chat`.

وللتأكد إن الديسكتوب سليم: افتح الموقع نفسه في ويندو عريضة — الشكل الأصلي زي ما هو.
